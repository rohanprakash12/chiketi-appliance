CHIKETI APPLIANCE

v0.1 // REMOTE MONITOR
A RASPBERRY PI THAT MONITORS YOUR SERVERS. SSH in, pull stats, and display them on a beautiful kiosk dashboard — with nothing installed on the servers themselves. Watch one box or many: CPU, memory, disk, network, GPU, temperatures, and fans, all over read-only SSH. Companion to chiketi (which monitors the local machine).

The appliance SSHes into each server and runs standard read-only commands (/proc/stat, free, df, nvidia-smi, …) in a single roundtrip per host every 1.5s. No root, no daemon, no package to install on the remote.
